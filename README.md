# ericpricemagic.com — site files

Three self-contained HTML files (no build step, no dependencies to install — each file has its fonts, styles, and photos baked in). `index.html` is the live homepage; the other two are alternate looks you can preview any time or switch to later.

- `index.html` — Marquee Bill (the one that's live)
- `casino-noir.html` — Casino Noir alternate
- `vintage-parlor.html` — Vintage Parlor alternate
- `.nojekyll` — tells GitHub Pages to serve the files as-is, no processing

## Two things still need your real info before this is bookable

1. Stripe payment link — search each file for REPLACE_WITH_YOUR_PAYMENT_LINK and swap in your real Stripe Payment Link.
2. Testimonial inbox email — search each file for YOUR-EMAIL@example.com and replace with your real email (uses formsubmit.co, free, no account needed).

## Switching which version is live

Rename files — whichever one is index.html is what visitors see.
